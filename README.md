# 🧠 Obsidian Vault

Особиста база знань з автосинхронізацією через GitHub.

## Структура

| Папка | Призначення |
|-------|-------------|
| `00 - Inbox` | Нові нотатки, необроблені думки |
| `10 - Projects` | Активні проєкти |
| `20 - Areas` | Зони відповідальності |
| `30 - Resources` | Корисні матеріали, посилання |
| `40 - Archive` | Завершені проєкти та архів |
| `50 - Templates` | Шаблони нотаток |

## Синхронізація

Vault автоматично синхронізується з GitHub через плагін **Obsidian Git**.
- Автозбереження кожні **10 хвилин**
- При закритті Obsidian — автокоміт
